Tempat menaruh foto dan video lokal untuk website ini.

Cara pakai:
1. Simpan foto/video kamu di folder ini.
2. Buka src/data/gallery.ts untuk mengganti foto galeri.
3. Buka src/data/video.ts untuk mengganti video utama dan thumbnail.

Contoh path:
- public/media/foto-1.jpg dipanggil di kode sebagai /media/foto-1.jpg
- public/media/video-kita.mp4 dipanggil di kode sebagai /media/video-kita.mp4
- public/media/thumbnail-video.jpg dipanggil di kode sebagai /media/thumbnail-video.jpg

Format yang disarankan:
- Foto: .jpg, .jpeg, .png, .webp
- Video: .mp4 atau .webm
